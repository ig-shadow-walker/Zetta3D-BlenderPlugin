# Contributing

Thanks for helping make Zetta 3D for Blender better.

## Issues are welcome

- **Found a bug?** [Open a bug report](https://github.com/ig-shadow-walker/Zetta3D-BlenderPlugin/issues/new?template=bug_report.yml)
  with your add-on version (Preferences › Add-ons › Zetta 3D), your Blender version and system, and the steps
  that show it. Blender's console (Window › Toggle System Console on Windows; start Blender from a terminal on macOS
  and Linux) often has the error that explains it.
- **An idea?** [Suggest a feature](https://github.com/ig-shadow-walker/Zetta3D-BlenderPlugin/issues/new?template=feature_request.yml).
- **A security problem?** Please don't open an issue — see [SECURITY.md](SECURITY.md).
- **Your account, credits or a generation?** Those are on zetta3d.ai: [support](https://zetta3d.ai/support).

## Code contributions

The add-on is source-available, not open source (see [LICENSE.md](LICENSE.md)): we don't take pull requests unless
we've agreed on one in advance. If you'd like to change something, open an issue first and say what and why.

## Working on it

The [README's Development section](README.md#development) has the layout of the code, how to run the tests (headless,
in a throwaway Blender user folder) and how to build the zip.
